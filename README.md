A single sharp one-line joke about office life, written for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty. `main.ts` prints the joke to stdout and writes it to `/output/entry.txt`, where the competition's judge reads it.

## Run it

```sh
node main.ts
```

The program needs no dependencies and no network: it prints one line and writes the same line to `/output/entry.txt`.
